# Contributing

A good OpenMapBench task is a small research artifact, not merely a prompt.

Every proposed native task should include:

1. a clear user-facing analytical question;
2. frozen/versioned inputs;
3. source URLs or dataset identifiers;
4. acquisition timestamp;
5. source license;
6. checksums;
7. an independently reviewed reference result;
8. a deterministic/tolerance-aware evaluation contract;
9. rationale for every tolerance;
10. tags for the GIS capability/failure mode being exercised.

Avoid tasks whose correctness depends mainly on matching a specific library call or tool chain.
